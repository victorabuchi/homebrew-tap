# Homebrew tap

Casks for [Notchlight](https://github.com/victorabuchi/notchlight): lock screen widgets and a Dynamic Island for your Mac's notch.

```sh
brew install --cask victorabuchi/tap/notchlight
```

Notchlight updates itself, so `brew upgrade` leaves it alone unless you pass `--greedy`. Requires macOS 15 or later.
